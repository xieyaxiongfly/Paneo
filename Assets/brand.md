# Paneo · 窗格

Paneo takes its name from “pane”: independent file panes combined into a workspace.
The app icon uses the logo directly, with a midnight navy tile and cyan/blue panes forming an abstract P.

Created using the built-in image_gen tool. Design proposal; name availability has not been checked.

## Generation prompt

Create one finished macOS app icon for Paneo, a refined multi-pane file manager. No text or letters printed, no mockup, no icon sheet. A single strong abstract P-shaped mark constructed from three softly rounded rectangular window panes: tall left vertical pane and two stacked shorter panes on upper right, with precise negative-space gutters suggesting split-view workspaces. Cyan to cool sky-blue luminous panes on deep midnight navy rounded-square app tile. Sophisticated restrained macOS native aesthetic, subtle dimensional bevel and very soft light, almost flat, not glassy, no excessive gradients, no decorative particles or tiny details. Bold silhouette recognizable at 16px. Tile centered and occupies 88 percent of a square 1024x1024 canvas, equal transparent padding around it. Genuinely transparent outside the rounded tile. Front view perfectly straight, symmetric tile, no perspective. Production-ready app icon; no additional symbols, no folder clipart, no Apple or Finder face.

## Files

- `Paneo-logo.png`: original image-generation output, used directly as the app icon artwork.
- `AppIcon.icns`: macOS icon sizes, packaged with `scripts/build-icon.sh`.
